# Saevyn Reverie Community v1.5.10 — friends test

I made a shareable, editable edition of my Reverie ChatGPT skin. It is built directly from Reverie 1.5.10, with the same theme looks, appearance controls, responsive layouts, reactions, and themed menus/dialogs.

This public package is deliberately neutral and image-free: no household portraits, divider artwork, favicon images, or names; no telemetry or conversation storage. Speaker headers use an emoji portrait anchor, a CSS hairline, and a vertical message thread. Fresh installs begin with two speakers, and the in-page settings panel can add or remove speaker slots while controlling the full Reverie appearance system, fonts, names, and detection symbols; the configuration block near the top also lets you add your own page background.

It is a public test because ChatGPT's interface changes often. If something breaks, please send the browser/userscript manager, the Saevyn version, what screen you were on, and a screenshot with private chat text hidden.

Install instructions and the privacy boundary are inside the ZIP. This is an independent community project and is not affiliated with OpenAI.
