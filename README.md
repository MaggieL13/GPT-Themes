# GPT Themes

Browser-side themes for ChatGPT, packaged as self-contained userscripts.

## Available themes

### Saevyn Reverie Community

An atmospheric, highly configurable ChatGPT skin with multiple palettes and visual looks, responsive layouts, reaction styling, readable menus, and optional emoji-based speaker separation.

- **Version:** 1.5.10
- **Images bundled:** none
- **Telemetry:** none
- **Conversation storage:** none
- **Userscript privileges:** `@grant none`

[Install the userscript](https://raw.githubusercontent.com/MaggieL13/GPT-Themes/main/themes/saevyn-reverie-community/saevyn-community.user.js) · [Read the theme guide](themes/saevyn-reverie-community/README.md) · [Download the release ZIP](releases/saevyn-community-v1.5.10.zip)

## Installation

1. Install a userscript manager such as Tampermonkey or Violentmonkey.
2. Open the **Install the userscript** link above.
3. Review and install the script.
4. Reload [ChatGPT](https://chatgpt.com/).

The lower-right gear opens the appearance panel. Preferences remain in local browser storage. Use `Alt+Shift+C` to pause or resume the theme.
